# 醒醒吧！方块 · Wake Up, Cubes!

一款清新可爱的 3D 体素解谜游戏：看方块上的数字，敲掉多余的方块，唤醒沉睡的小伙伴。
网页、手机、Meta Quest 2/3 浏览器（WebXR）都能玩，还能自己创造关卡分享给朋友。

**纯前端静态网站，不需要后端。** 直接放到 GitHub Pages / Cloudflare Pages / 任意静态服务器即可。

## 玩法
- 方块某一面上的数字 = 垂直穿过这一面的那一整排里，要保留的方块数量
- 数字下有 2 个粉色圆点 = 这些方块分成 2 段；3 个紫色圆点 = 3 段或更多；`0` = 整排敲掉
- 电脑：左键敲除、右键保护、拖动旋转、滚轮缩放；手机：点击敲除、长按保护
- X / Y / Z 滑块一层层剥开外壳；敲完所有多余方块，小伙伴就会醒来并动起来
- Quest：扳机敲除、侧握键保护、A/X 切换工具、摇杆旋转方块，左侧悬浮面板可以切片、选关、回主页、在 VR 里创造关卡（扳机放方块、侧握键擦除）

## 功能
- 10 个官方关卡（5×5×5 到 12×12×12），全部可以纯逻辑解开，不需要猜
- 唤醒动画：躯干呼吸、左右摆动、旋转、弹跳、环绕漂浮（partId 0–5），眼睛会眨
- 生态收藏室：环形展台展示所有唤醒的小伙伴，点它会跳
- 造物工坊：3–12 任意尺寸、22 色马卡龙色板、动作部件、镜像对称、撤销重做、预览动画、试玩、模板
- 分享：关卡压缩成链接 `?share=...` 或关卡码，无需服务器跨设备分享；分享图只显示还没唤醒的谜题方块和「快来唤醒我吧！」，不剧透；二维码只放短网址（官方关卡带 `?lv=` 扫码直接进关）
- 后台管理（首页右上角）：生命值、休闲模式、动画速度、音量、四套主题；关卡库改名/难度/排序/编辑/删除/导入导出 JSON
- 音效全部用 Web Audio 实时合成

## 需要你改的地方
| 要做的事 | 怎么做 |
| --- | --- |
| 绑定域名 | 打开 `js/config.js`，把 `SITE_URL` 改成你的网址（分享图、二维码、分享链接都会用它）。留空则自动使用当前网址 |
| 放 Suno 背景音乐 | 把 mp3 放进 `music/`，命名 `bgm1.mp3`、`bgm2.mp3`…（最多 8 首）即可自动轮播；想指定曲名/场景就编辑 `music/playlist.json`。没放音乐时播放 3 首内置曲子（八音盒摇篮曲、星星糖华尔兹、泡泡散步）；每次进关随机挑一首音乐和一个场景主题，关卡中一直是这首，不会切换 |
| 让所有玩家看到后台改动 | 后台的修改只存在你自己的浏览器。点「导出 JSON」，把文件改名为 `game-pack.json` 放进 `data/` 再上传，所有玩家都会使用这份关卡库和配置 |

## 本地运行
```bash
python -m http.server 8000
# 打开 http://localhost:8000
```
（必须通过 http 打开，直接双击 index.html 无法加载模块。）Quest 上要进入 VR 必须是 https 网址，GitHub Pages 自带 https。

## 文件结构
```
index.html            页面骨架
css/style.css         毛玻璃卡片 + 糖果按钮样式
js/main.js            界面流程、分享、后台、VR 面板
js/world.js           渲染器、天空小岛、相机、鼠标触摸、WebXR 手柄
js/voxel.js           数字图集、圆角方块着色器、提示计算、网格射线、动画模型
js/play.js            解谜模式（敲除/保护/切片/唤醒）
js/levels.js          10 个关卡的程序化体素生成器
js/creator.js         造物工坊
js/collection.js      收藏室
js/share.js           分享图 / 二维码 / 缩略图
js/codec.js           关卡码编解码
js/store.js           本地存档
js/audio.js           音效合成 + 背景音乐
vendor/               three.js r160、qrcode-generator（MIT）
```
